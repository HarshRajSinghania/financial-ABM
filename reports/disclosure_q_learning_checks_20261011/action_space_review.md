# M4 下一版动作集审查（设计，未实现）

建议下一版采用**配置中预先固定的多幅度、可变内部 Q 动作数**，对外仍只有真实改善、虚报、维持三种含义；默认 `firm_action_fractions=(.01,)` 保留旧行为。两端点 `(.01,1)` 是最小5动作方案，但容易漏掉有利的中间幅度。若目标还包括可说明的局部离散精度，推荐候选 `(.01,.02,.04,.08,.16,.32,.64,1)` 先进入数学/组件验收；其相邻比例不超过2，与自然衰减、连续 NPV 最优解、结果正负或政策排序无关。该网格是探索性假设，不是经验投资规模估计。当前实现、参数、8世界归档及覆盖 FAIL 均保留；本文不授权新增运行预算。

## 已核实的限制

当前 [共同候选](../../src/abm/disclosure/learning.py:41) 为 `delta=rho*C`，其中 `rho=.01`、领域单期上限 `C=.25`，每60日决定一次。真实改善120日后应用；每日先自然衰减，再应用到期项目，并尊重属性上下界和在途容量预留，见 [状态推进](../../src/abm/disclosure/game.py:107) 与 [决策调度](../../src/abm/disclosure/game.py:506)。所有量使用固定初始 SD 的 goodness 单位，不把评级当潜在真值。

设年衰减 `d=.2`、决策间隔 `D=60`。内部区间每周期损失 `d*D/252=.047619 SD`，而当前最大投入仅 `.0025 SD`，长期全选真实改善也最多 `.0105 SD/年`。1800日、首次决策在60日、实施延迟120日时，至末日仅28次真实决定能生效，投入上界 `.07 SD`，内部累计衰减 `1.428571 SD`。下界裁剪会减少实际衰减，因此该差额不能直接套到每家公司或下界附近。

这说明净变化受可行集约束，不能由此判定 QL 不会投资或政策无效。它也不消除另一个独立问题：[归档 summary](../disclosure_q_learning_smoke_20261011_v1/summary.json) 中173/1800=9.61%的验证状态未被训练访问，覆盖门槛仍 FAIL。已有 `decay_adjusted_gain` 应与绝对变化同时保留；相对自然衰减基线的增益与绝对净增长含义不同。

## 三种方案

| 方案 | 共同候选和 Q 维度 | 优点与边界 |
| --- | --- | --- |
| 单个固定 rho | 每类一个幅度，保持3动作 | 改动最少，适合预先固定的幅度敏感性对照；不能学习投资强度。rho 改大既增收益也按平方增成本，不应跑到正号后挑一个 rho。 |
| 多个预先幅度 | 每个非零业务动作有 J 档，内部 `A=2J+1` | 能在同一环境中学习行动类别与幅度，离散 NPV 可完全共享可行集。两档即5动作，是实现幅度选择的最小扩展；覆盖和探索成本增加。 |
| 可观察资源预算定幅 | 预设毛资源支出比例 b，`delta_a=min(C,H_a,sqrt(b/c_a))`；单档仍3动作 | `c_real=c`、`c_wash=omega*c`，使资源支出不超过 `b*P_t`。幅度由当前成本、容量与事先预算确定，不使用 NPV；若有多档预算仍需更多内部动作。b 未校准，不能当公司可支付现金或真实投资约束。 |

资源预算方案会使低成本公司买到更大改善、虚报因成本较低买到更大幅度，改变了规模/行动之间的比较口径。当前公司没有现金账户；`b*P_t` 只能称模型中的毛资源支出限额，不能称 cash buffer、融资缺口或偿债能力。罚金、补贴另列，不能用补贴抵销资源预算来无声改变候选；既有价值锚耗尽失败也不能用下界或自动缩单掩盖。该方案需要额外预算依据，暂不推荐作为最先实施版本。

## 推荐合同及最小触点

动作目录可为 `[改善rho0, 虚报rho0, 维持, 改善rho1, 虚报rho1, ...]`，业务映射为 `[0,1,2,0,1,...]`。QL 的 `A=2J+1` 列分别学习，不能把多档混进同一个 Q 值后由 NPV 选择幅度。市场沿用原业务动作、金额、队列和实际台账；单独归档候选 ID，供 TD 与覆盖核验使用。离散 NPV 和 QL 必须获得逐项相同的候选金额、成本、延迟、容量与合法掩码；负 NPV 不自动非法，QL 奖励仍只取实际账目。连续 NPV 仍是不同可行集的辅助参考。

几何网格的有限依据：对单一凹二次局部效用 `U(x)=a*x-c*x^2`、`c>0`，若内点最优 `x*=a/(2c)` 位于非零网格范围内，相邻比率≤r，则最近候选的相对效用损失≤`((r-1)/(r+1))^2`，r=2时≤1/9。这里使用局部效用作离散化诊断，不生成 QL 候选、标签或奖励。首格以下、报告容量的斜率 kink、以及实际市场中大额行动改变需求/融资系数，均不享有这个全域精度保证。需在预先固定的状态面板中单列它们的绝对差额，不能按结果自适应加点后仍声称原网格已验收。

8档意味着17个内部动作；全合法的常见状态至少需要340条训练动作记录，原3动作仅需60条。覆盖分母仍按实际决策数，计数必须按内部候选分别核验，不能把同类幅度合并使其通过。它的内存开销很小，但覆盖与预算代价真实存在；原2训练世界不构成新网格训练充分的依据。

容量截断后多档可能相同：保留固定目录中靠前的候选，屏蔽重复项，零幅度屏蔽，维持始终合法。探索应先在合法业务类别中均匀，再在该类合法幅度中均匀，避免全合法时新增幅度把维持概率从1/3无声降为 `1/(2J+1)`；最大 Q 并列时同样须预先规定类别/幅度规则，冻结评估可用维持→改善→虚报、类内小额优先。

必要源码触点仅是动作维度贯通：`CompanyQLearner.__init__` 增加可选 `actions=3`，数组分配用该维度，`choose` 上界取 `values.shape[2]-1`；这比构造后替换数组更完整，不需 subclass/wrapper，旧默认3维行为不变。其余为 config 的网格、`disclosure/learning.py` 的目录/候选/掩码/选择/更新/冻结形状、`game.py` 的候选 ID/业务动作映射和历史、`runner.py`/`training.py` 的合同/表形状/覆盖。披露训练仍不用 legacy update。旧3列合同/档案继续按旧版本读取，不迁移旧 Q 为新维度训练起点。新合同冻结幅度目录、去重和探索规则、单位、动作数及格式版本；不改变融资预测、延迟、实际奖励或自然衰减参数。默认81状态和6组可先保留，但完整队列、承诺金额、容量/收益状态等仍未被完整观察，动作增加不使模型自动满足 Markov 性。

## 先验验收边界与顺序

1. **先做物理可行性检查。** 无上下界裁剪和容量拥堵时，长期抵消衰减至少需要 `delta_max >= d*D/252`；要允许严格净增长需严格大于。等价 `rho_neutral=d*D/(252*C)=.190476`。若该值大于1，现有单期物理上限本身不足，应报告不可行，不能为得到正号改变 d 或 C。边界只判断候选是否允许抵消衰减，不是推荐投资规模或经验校准值。
2. **有限窗口不能只用年化上界。** 对窗口 `(s,T]`，逐一计数 `s < decision_day+max(1,L_real) <= T` 的项目，区分 carry-in 与末期在途。用确定性属性推进验收恒等式 `g_T-g_s = sum(实际应用真实增量)-sum(实际自然衰减)`；实际增量扣除上界裁剪，实际衰减扣除下界裁剪。无拥堵的成熟项目投入上界不足以覆盖内部损失时，不允许把该窗解释为有机会扭转净衰减；上界足够仍不是可达性或收益性证明。
3. **经济收益单独验收。** 相同的扩大幅度带来 `c*delta^2` 成本，融资收益有限、实施等待折现、报告饱和还会挤出旧虚报。先用手算小环境检验共同候选、应用时序、正/负收益与大额支出失败；这些是公式/机制测试，不以市场结果调网格。不得把连续 NPV 的最优幅度、排序或价值变成 QL 候选、奖励或标签。
4. **最后才冻结预算。** 新幅度可能改变状态分布和失败率，旧2训练世界的表与覆盖不能复用为新版本验收。先通过动作目录/容量/去重/探索/TD/旧3动作退化测试，再另定训练与验证预算；保留所有失败，继续要求未访问比例≤5%、常见状态每个合法内部动作至少20条训练记录。新增动作不自动允许追加预算直至结果有利。

上述方案只让共同可行集包含更宽的行动范围。自然衰减、容量、成本与融资收益目前均含未校准假设；更大的合法动作可能是负 NPV，冻结 QL 也可能选择维持或虚报。没有正向净改善、学习充分、政策优越或实证有效性的预设结论。
