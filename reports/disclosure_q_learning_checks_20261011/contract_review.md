# M4 集成前只读合同审查

此文保留实现前的验收合同；当前代码审查与确定性检查结论见review.md。组件检查不能代替M4训练、冻结评估及覆盖验收。

1. API须拒绝非QL模式携带learner或training=True。QL训练显式接受可写表；评估显式接受只读表、epsilon=0。每个1800日世界只携带Q与计数进入下一训练种子，前驱动作、奖励窗口、市场状态和事件队列都重新初始化；不把新世界状态拼接到旧世界的TD转移。

2. 运行身份至少含training标志及Q初始值/计数内容身份，归档绑定冻结表文件SHA。评估检查源码、除seed之外的市场配置、训练规模、领域、政策及完整动作/状态/奖励合同。排除seed是为了允许明确的训练/验证分组，不允许任意宽松忽略其他配置。评估前后Q与counts逐位相同；每世界Q初末、有效epsilon、学习率、年度贴现及训练序号均留档。learning.load_frozen的可选元数据/哈希校验必须由runner实际传入，表形状正确不足以证明适配。

3. 状态在交易、核查之后及新动作之前记录；包含次日待应用罚金等已知责任。上一行动的奖励窗只含(start,end]内实际应用的原币事件及每日实际融资基准差额，按固定初始市值归一；不能从NPV、预期罚金、价格收益或估值变化再补奖励。融资差额可继续来自较早项目，不能把它当最近行动的因果增量。待应用现金stage应依据实际承诺/事件，不能只凭资源成本、罚金与补贴相抵后的净pending_value_change判断是否无责任。

4. 核查日t产生的罚金在t+1应用，归新区间；事件可由(run,period,firm,reason)唯一索引，成本与补贴归该决策，罚金归该次核查的聚合虚报存量，不能标成t日刚选的新动作或伪造逐项目wash归责。分项周期金额与次日应用台账支持总账核对，成本与补贴不按应用日市值再次缩放。最后完整转移使用同世界审计后next_group/state/合法mask bootstrap；时间上限不设吸收终止。无完整下一窗口的末动作只列未结项目、承诺与未查获虚报，不补零奖励样本。

5. npv_discrete和QL共用固定rho、容量、金额、资源成本、补贴及同一调度。负NPV不使正容量动作非法；QL不使用候选效用或排序作状态、奖励、标签。continuous npv原有数值路径及环境/审计/信号/模仿RNG保持；新增探索流独立。训练失败保存失败seed、部分市场进度与部分Q，不丢弃失败经验再冒称固定预算完成；失败后是否续训应预先明确。

6. 覆盖以(group含实际policy_epoch,state)作为键，分母预先固定为评估公司决策访问数，不能只数distinct states。未访问state看训练counts之和为零；常见state的合法动作集合取该键评估实际mask的并集，不能仅取被选动作或任意一次mask。每个共同合法动作≥20条训练记录的门槛应用已结算经验计数，不混入仅访问未结算的末动作。按组/制度与种子列出覆盖，保持未访问率≤5%、常见访问占比≥1%门槛，不在看过评估后改阈值补训。

learning.batch_update使用旧Q整表快照、next_groups和合法动作mask，且不调用旧tabular.update，方向符合设计。save_frozen保存旧discount字段，实际batch_update则使用年度率与elapsed_days；归档必须明确有效贴现规则，避免把默认.9误称实际周期gamma。未完成集成、端到端训练及冻结评估前，组件和玩具测试通过均不能称M4完成。

本审查不会要求完整Markov状态、完整企业现金账户或完整均衡识别；固定报告容量、未计旧虚报避免罚金及共享表部分观测近似按已明确设计评估。
