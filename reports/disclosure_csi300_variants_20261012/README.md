# 沪深 300 经验初始化：主设定与两个对照的开发实验（2026-10-12）

> 注：沪深 300 华证派生的领域文件和三个开发网格目录包含华证评分的汇总分布，是否公开尚待确认，暂未放入公开仓库；本文中指向它们的链接暂时无法打开。

**性质：开发实验，不是确认性结论。** 规模为 150 名投资者、30 家公司、1800 日（预热 600 日），使用 3 个已经观察过的开发种子（23001–23003）。机制参数和成本参数仍是 `esg.json` 中未经校准的假设值。

## 设计

三个 spec 与 `disclosure_financing_development_v1` 的场景、种子和融资假设完全相同，只更换领域文件，市场一律使用 `intrinsic_value_log_sd = 0.9152`（ln 市值，研究契约第 14 节）：

| 变体 | spec | 结果目录 |
|---|---|---|
| 主设定：分位数映射 + 规模 copula（ρ=0.1767） | [spec](../../configs/disclosure_csi300_quantile_copula_development_v1.json) | [report](../disclosure_csi300_quantile_copula_development_20261012_v1/report.md) |
| 对照：分位数映射，ρ=0 | [spec](../../configs/disclosure_csi300_quantile_independent_development_v1.json) | [report](../disclosure_csi300_quantile_independent_development_20261012_v1/report.md) |
| 对照：旧线性映射（满分对应 +1.72 SD） | [spec](../../configs/disclosure_csi300_linear_development_v1.json) | [report](../disclosure_csi300_linear_development_20261012_v1/report.md) |

每个变体 15 个场景 × 3 个种子 = 45 个试验，全部完成。跨变体比较由 [compare_variants.py](compare_variants.py) 生成 [comparison.json](comparison.json)，只读取已归档的输出，不做新模拟。不同映射下 SD 单位不可比，所以跨变体只比较评分单位的指标。

## 结果

1. **机械门槛**：每个变体都有 15/45 个试验 FAIL，三个变体的失败集合完全相同：种子 23002 的全部 15 个场景，原因是价格截断，与领域设定无关。旧的融资开发实验（默认 ESG 领域）同样是 15 个失败。这些失败没有删除，计入下面所有区间。
2. **天花板在这个网格中没有触及**：基准场景 `market_B` 结束时，三个变体都没有公司位于上界或距上界 0.25 SD 以内（线性对照的上界为 +1.72 SD）。自然衰减占主导：1200 日测量窗口内，平均评分变化为主设定 −6.47 分、ρ=0 对照 −6.60 分、线性对照 −5.16 分。变体之间的差异来自映射的非线性，不是天花板。
3. **没有漂绿，政策对比全部为 0**：三个变体合计 125,550 次企业决策中，“改善”约 56,600 次，“漂绿”0 次。透明度和罚款只通过漂绿起作用，所以信息、罚款、两者组合及其与市场的交互，所有对比都精确为 0。这个网格无法检验三项设定对政策结论的影响。
4. **市场偏好效应（market_B − zero_taste_B，测量窗口评分变化）**：三个变体方向一致。主设定 +2.50 分 [−0.22, +5.23]，ρ=0 对照 +2.32 [+0.28, +4.37]，线性对照 +1.73 [+0.53, +2.93]。变体之间的配对差异区间都跨零：主设定减线性 +0.77 [−0.95, +2.50]。
5. **copula 的可见影响**：在市场偏好效应的规模差（大企业减小企业）上，主设定比 ρ=0 对照低 1.71 分 [−2.26, −1.16]。一个可能的机制是：加入相关后，大企业起点更高，而边际成本随属性水平指数上升（`cost_level_elasticity`），于是大企业改善得更少。只有 3 个种子，未做多重比较校正，只能作为开发观察。

区间是 3 个种子的配对 t 区间，未作校正，不包含参数和模型不确定性。

## 含义

- 三项初始化设定已经可以运行，在这个网格里也没有改变市场偏好效应的方向。
- 目前真正的瓶颈不是初始化，而是企业行为：在融资开发参数下，企业从不漂绿，政策工具因此完全不起作用。旧的报告频率开发实验在零罚金条件下出现过漂绿，所以是否漂绿取决于参数区域。下一步应先诊断什么条件下漂绿会成为企业的最优选择，并且不能为了得到政策效果而调参。
