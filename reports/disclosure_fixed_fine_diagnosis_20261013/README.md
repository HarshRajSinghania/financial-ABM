# 阶段 B：让企业的博弈真正发生（2026-10-13）

**性质：开发实验，不是确认性结论。** 契约规模（1000 名投资者、200 家公司、3500 日，第 1201 日起执行政策），3 个新开发种子 28101–28103，每个场景 3 个配对种子。区间是未作多重比较校正的配对 t 区间，不含参数和模型不确定性。

## 结论

**验收通过。** 计划的验收条件是“开发网格中出现非零漂绿，并且信息型、惩罚型政策的对比不再机械地为 0”，两条都满足：基准场景中 51% 的政策窗口决策选择漂绿，160/200 家企业漂绿过；信息政策与惩罚政策在漂绿存量上相差 −0.82 SD [−1.36, −0.27]。

但漂绿的量级主要由两个机制决定，解读时必须带上：

1. **边际威慑失效。** 定额罚款每次查处罚一笔（契约第 16.1 条），所以已在漂绿的企业再追加虚报不多交罚款。政策窗口中 96% 的漂绿决策是“延续”而不是“开始”，66% 的漂绿幅度顶到了每期上限 0.25 SD。
2. **评分天花板没有建模。** 投资者对潜在报告值线性定价，但可观测评分在 100 分处饱和（契约第 14 节已登记为未实现）。基准场景中 27% 的漂绿决策发生在报告已经超过满分之后；期末平均虚报达到 3.9 SD，部分企业的报告顶到了 ±6 的数值边界。

## 3. 三项诊断

### 3.1 漂绿确实发生

基准场景政策前有 16% 的决策选择漂绿，政策窗口内为 51%。不过开启新案件的决策很少：没有未被发现虚报的企业中，每期只有 4.2% 开始漂绿；已有未被发现虚报的企业中，93.9% 继续漂绿。漂绿幅度平均 0.21 SD/期，是真实改善（0.026 SD/期）的 8 倍。

### 3.2 罚款占市值的比例随规模下降，大企业更倾向于漂绿

- 罚款占市值比例的中位数：大企业 8.7×10⁻⁶，中型 2.5×10⁻⁵，小企业 9.3×10⁻⁵，相差约 10 倍。
- 政策窗口的漂绿决策占比：大 82%、中 72%、小 35%。等成本对照中为 76%、69%、34%，梯度几乎不变，说明主要来自 F/P，而不是成本乘子。
- 按市值十分位看“开始漂绿”的比例：从最小一档的 0.8% 上升到最大一档的 8.5%，中间几档有小幅起伏（2.6%–5.5%）。
- 命题 1 的闭式阈值与实际选择的一致率：开启新案件的决策中为 99.4%；产能约束不生效的子集（占 93%）中为 100%。

### 3.3 透明度门槛附近的过渡：门槛以下逐步下降，门槛处仍有跳变

| 透明度 τ | 0 | 0.1 | 0.3 | 0.5 | 0.55 | 0.575 | 0.6 |
|---|---:|---:|---:|---:|---:|---:|---:|
| 条件重算：全部决策 | 55.6% | 50.9% | 41.3% | 34.6% | 31.0% | 0 | 0 |
| 条件重算：开启新案件的决策 | 11.5% | 4.2% | 0.4% | 0 | 0 | 0 | 0 |
| 条件重算：去掉罚款 | 98.1% | 96.9% | 89.0% | 82.4% | 78.8% | 0 | 0 |
| 实际运行（第 1201 日起改变 τ） | — | 50.9% | 22.8% | 14.8% | — | — | 0 |

条件重算基于基准场景政策窗口记录下的状态，只改变 τ 重新计算当期选择，不产生新的市场路径。

- 定额罚款把开启新案件的门槛分散开：企业门槛 τ_i* 的中位数为负，第 95 百分位数为大企业 0.25、小企业 0.08。因此“开始漂绿”随 τ 平滑下降，到 0.5 已降为 0。
- 已在漂绿的企业没有边际罚款，门槛都是共同的 τ* = 0.565（命题 2 推论 3）。所以总体比例在 τ* 处从约 31% 跳到 0。
- 产能上限也会让门槛分化：去掉罚款时，比例在 τ* 以下仍从 98% 降到 79%。这与 2026-10-12 的“全有或全无”不同，那时幅度很小，没有触及上限。
- 结论：门槛以下的过渡是合理的、渐进的；门槛处的跳变来自边际威慑失效，是“每次查处罚一笔”这一设定的直接后果，不是数值问题。

### 3.4 边际威慑：惩罚政策阻止开始，阻止不了继续

与基准相比，罚款提到 4 倍后，“开始漂绿”的比例从 4.2% 降到 1.0%，“继续漂绿”只从 93.9% 降到 89.4%。漂绿减少主要是因为开启的案件变少，以及旧案件被查处后不再重开（政策窗口中有未被发现虚报的决策从 11,858 次降到 6,234 次）。信息政策 τ = 0.6 高于共同门槛，4,427 次带着旧案件的决策全部转为真实改善。

## 4. 需要研究决定的问题（未改任何设定）

1. **评分天花板（已处理：契约第 17 节实现了评分饱和，结果见[第二版](../disclosure_saturation_diagnosis_20261013/README.md)）。** 基准场景中 16.5% 的企业日报告超过满分，27% 的漂绿决策发生在超过满分之后（提高罚款后为 41%），期末平均虚报为 3.9 SD，部分企业顶到 ±6 的数值边界。在现实中，超过满分的虚报对投资者不可见。按契约第 14 节，实现信号饱和必须同时改写融资因子和 NPV 中的线性信号假设，作为单独的模型变更先写入契约。
2. **罚款记账。** 现在按“每次查处罚一笔”（契约第 16.1 条），它直接造成了边际威慑失效和门槛处的跳变。另一种读法“每份虚假报告各罚一笔”会让每次追加虚报都承担罚款。两者是不同的制度假设，应当选定一个作为主设定，另一个作为对照，不能按结果挑选。
3. **比例罚对照的量级。** 0.005/SD 下没有任何漂绿，“定额罚 vs 比例罚”的形式比较因此退化为“有漂绿 vs 无漂绿”。阶段 F 若要比较两种形式，需要事先约定一个可比的比例罚水平，例如在中位企业上与定额罚有相同的期望罚金。
4. **成本随真实水平下降。** `cost_level_elasticity = 1.5` 让漂绿成本随真实属性下降而降低；自然衰减使真实属性持续下降，于是漂绿越来越便宜。这是既有假设，w = 0.2 也没有经验依据（契约第 15.5 条）。
