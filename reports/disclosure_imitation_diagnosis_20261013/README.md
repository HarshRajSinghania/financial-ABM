# 阶段 C：影响力投资者的增长是选择还是漂移（2026-10-13）

**性质：开发诊断，不是确认性结论。** 设计、修正规则和验收标准都在运行前写入[研究契约第 18 节](../../docs/disclosure_research_contract.md#18-投资者模仿机制的诊断与修正2026-10-13-固定先于任何诊断运行)。主设定（第 14–17 节），全程基准政策，契约规模 1000 名投资者、200 家公司、3500 日，新种子 29001–29020，每格 20 个种子，共 240 个世界。区间是跨种子的 95% t 区间，未作多重比较校正。

## 结论

1. **原来的模仿规则以漂移为主。** 每个复核者直接比较两类投资者的平均增长率，没有先随机抽取比较对象。于是业绩差一有噪声，占比就被推向 ½：零偏好时，初始占比 0.2 平均上升 +0.053，初始 0.8 平均下降 −0.069，初始 0.5 不动。按记录的业绩差计算，初始 0.2 时约 92%、初始 0.8 时约 90% 的变化来自规模不对称项。有偏好时，0.2 的上升（+0.19）中也有一半来自这一项。
2. **修正规则通过验收。** 按 Schlag (1998) 的原意，每个复核者先随机抽取一个对象，只有对方类型不同时才比较。修正后：(a) 零偏好时三个初始占比的变化都与 0 无异；(b) 有偏好时，相对零偏好的配对增量为 +0.0225 [+0.014, +0.031]，可以与噪声区分。
3. **市场自身的转型动力很小。** 在修正规则下，14 年（3500 日）里偏好带来的影响力投资者占比增量约为 2–3 个百分点：taste 0.0635 时为 +2.3，按修正规则重新校准的 0.0724 时为 +2.7（后者为事后补充）。旧规则下是 +14 个百分点。
4. **复制动态基准：没有内部稳定点。** 影响力投资者每 60 日平均领先约 3 个基点，这一领先不随占比变化。在 [0, 1] 内没有零点，所以不存在稳定的共存比例；占比只会缓慢上升，从 0.2 到 0.5 约需 110 年。

## 1. 机制

记 s 为影响力投资者（II）占比，adv 为一期内 II 与 PM 平均财富增长率之差，k = 100，每期复核 m = 100 人（10%），p± = min(1, k·adv±)。

| 规则 | 一期内 II 人数的期望变化 | 业绩相等时 |
|---|---|---|
| 原规则 `type_mean` | m·[(1−s)p⁺ − s·p⁻] = m·(p⁺ − p⁻)/2 （选择）+ m·(½ − s)(p⁺ + p⁻)（不对称） | 只要 adv 有噪声且 s ≠ ½，就漂向 ½ |
| 修正规则 `pairwise` | m·N·s(1−s)/(N−1)·(p⁺ − p⁻) | 没有漂移（离散复制动态） |

修正只改变“与谁比较”，比较的仍是类型均值；k、复核比例和 60 日的评估窗口都没有调。原规则仍是代码默认值，已有结果逐位不变。

### 2.4 复制动态基准

把修正规则、有偏好三格的各期 adv 对 s 回归（按世界聚类的标准误）：截距 2.9×10⁻⁴（标准误 8.3×10⁻⁵），斜率 2.2×10⁻⁵（标准误 1.6×10⁻⁴）。II 的领先不随占比下降，按占比分档的均值在 1.4–3.4 个基点之间（另有两档少于 100 期，分别为 4.4 和 12.0），[0, 1] 内没有零点。零偏好三格的截距和斜率都与 0 无异。这只是 s 在 0.18–0.89 之间的有限范围描述，不能证明严格的演化稳定性。

## 3. 含义

- **按契约第 18.7 条，此后的主设定改用修正规则 `pairwise`。** 修正规则下偏好强度重新校准为 taste_median = 0.0724（第 18.6 条）。
- **阶段 B 两版结果都是在原规则下得到的。** 原规则让影响力投资者占比在政策窗口（第 1200–3500 日）里多涨了约 9 个百分点（+0.115 对 +0.022），政策前的溢价也因此偏高。校准已经修正了政策前的部分。但政策窗口内的融资收益和漂绿激励，在修正规则下可能更低。是否用新的主设定重跑阶段 B 网格，需要你决定；如果直接进入阶段 F，新主设定会自然覆盖这一点。
- **“市场自身的转型动力有多大”的回答：很小。** 在校准的偏好强度和现行模型假设下，模仿带来的影响力投资者扩张大约是每 14 年 2–3 个百分点。原来看到的“II 占比明显上升”主要来自更新规则的偏差，不是市场选择。这一结论依赖 k = 100、10% 的复核比例等未经验校准的假设：k 只改变速度，不改变方向。
