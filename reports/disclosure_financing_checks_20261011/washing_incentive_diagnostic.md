# 融资 v2 的零漂绿激励诊断

状态：开发诊断。使用 `disclosure_financing_development_20261011_v2` 的全部 45 份归档、归档内 `source.zip` 的 NPV/融资函数及真实 manifest 参数；不读取正在修改的工作区公式，不重跑市场，不改默认参数、阈值或种子。源码及结果哈希均已核对，明细和可执行脚本见同名 `.json`、`.py`。

## 已观察结果及识别范围

40,500 次公司决策中，真实改善 18,896 次、维持 21,604 次、虚报 0 次；全部路径的 inflation 为 0。全部正幅度改善都未触及行动上限或剩余容量，因此可由模型内点 FOC 反推其当时融资节约系数 b；这不是独立观测或现实融资效应估计。

恢复的 b 中位数为 0.0000419247，最大值 0.0002140279。另 4 个市场开启但维持的点，可从同公司其他期的成本恢复 b 的上界，最大 0.0000160548；其余维持来自零偏好、零 II 或融资通道关闭，归档规则给出 b=0。重复场景不是独立样本。

## 量纲和解析门槛

Δ 是固定初始 SD 单位。b 是每 SD 每年的融资费用节约，除以决策日市值，单位为市值比例/(SD·年)。真实/虚报年金 A_R、A_W 的单位为年；资源成本 cΔ² 中 c 的单位为市值比例/SD²，虚报成本系数为 ωc；罚金 π 和补贴 s 的单位为市值比例/SD。不能将这些系数统一称为“每 SD 的货币量”。

当前基线 p=.01/每60日、π=.005、透明度 τ=.1、ω=.2、企业年贴现率 .05、预测1260日、重定价60日、真实/披露延迟120/20日。归档公式给出：

- A_R=3.725762994 年，A_W=3.830453583 年。
- 最终罚金现值因子 K=0.455043818。因虚报存量持续存在直至查获，p>0 时最终查获概率为1；K 包含几何等待时间和折现，并非 p=.01。预期等待100个核查周期，约23.81交易年；它不是“当期 pπ”罚金模型。
- 漂绿线性净收益 L=b(1−τ)A_W−πK。只有 L>0 才有正幅度候选；二次成本下 Δ_W=min(capacity, L/(2ωc))。
- 基线正收益门槛 b>πK/[(1−τ)A_W]=0.000659980，是恢复最大 b 的3.08倍；样本尚未跨过此门槛。虚报便宜 ω=.2 也无法使负的线性收益变正。
- 无容量约束、无补贴且两种行动均内点时，漂绿胜过改善还需 b[(1−τ)A_W−√ω A_R]>πK；基线门槛为0.001277354。若括号非正，非负罚金/补贴下漂绿不能在该内点比较中胜出。这个式子不替代有容量约束时的逐候选比较。

| 归档政策 | 漂绿有正收益所需 b | 内点胜过真实改善所需 b |
| --- | ---: | ---: |
| B：τ=.1，π=.005 | 0.000659980 | 0.001277354 |
| I：τ=.6，π=.005 | 0.001484954 | 不存在正门槛，括号非正 |
| F：τ=.1，π=.02 | 0.002639918 | 0.005109418 |
| IF：τ=.6，π=.02 | 0.005939816 | 不存在正门槛，括号非正 |

π=.005 代表每虚报1 SD，查获时按当日市值收取0.5%；Δ=.25时为市值0.125%，不是0.005元、固定现金罚款或年度罚款。ESG初始SD=15分，π不经单位转换不能直接套用于现实每评分点的处罚。模型还假定罚金随查获日市值变化，未由执法数据估计。

## 小环境核对与研究含义

只做归档函数的理论候选计算，固定 c=.05、容量=.25、其余基线相同：最大观测 b 时选择改善；把罚金设为0的理论对照会选择虚报；跨过正收益门槛但未跨胜出门槛时仍选择改善；跨过胜出门槛后选择虚报。这排除了“程序硬禁止虚报”的解释。这些是冻结计算检查，不是运行新的政策实验，也不是调参建议。

同种子下 market_B/I/F/IF 的全部已记录数组（包括 NaN 诊断位置）完全相同。原因是原基线已无虚报，透明度不改变纯真实信号，增加虚报罚金也没有实际罚款对象。当前矩阵不能回答信息政策与罚金在存在漂绿时谁更有效；也不能把零罚金效应解释为现实惩罚无效。未来若研究存在漂绿的区域，应在正式种子之外先定义有依据的连续参数范围和识别目标，报告阴性区域，不为指定政策排序调参。

自然衰减是另一个独立变量：当前每年损失固定初始SD的0.2，未经验识别。公司持续投入真实改善时，全期 g 净变化仍可能为负；应分别报告改善投入/抵消衰减后的净转型及 `decay_adjusted_gain`。罚金门槛解释零虚报，不解释全部净负 g。

本诊断只覆盖三个开发种子和当前固定融资定价假设。v2 的15份归档仍未通过原 no-price-cap 门槛；尚无正式政策主张、处罚校准或现实融资传导结论。
