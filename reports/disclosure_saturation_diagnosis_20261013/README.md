# 阶段 B 第二版：加入评分饱和（2026-10-13）

**性质：开发实验，不是确认性结论。** 设计、剂量和开发种子（28101–28103）与[阶段 B 第一版](../disclosure_fixed_fine_diagnosis_20261013/README.md)完全相同，唯一的改变是[研究契约第 17 节](../../docs/disclosure_research_contract.md#17-评分饱和2026-10-13-固定先于任何使用这一机制的结果)的评分饱和。区间是 3 个种子的配对 t 区间，未作多重比较校正。

## 结论

1. **饱和按设计生效。** 政策窗口内没有任何报告超过满分，也没有任何一次漂绿发生在满分之上；第一版中这两个比例分别是 16.5% 和 27%。
2. **漂绿约减少三分之一，验收条件仍然满足。** 基准场景的漂绿决策占比从 51% 降到 33%，漂绿企业从 160 家降到 106 家，平均虚报从 1.85 降到 1.20 SD。信息政策与惩罚政策的对比仍不为 0。
3. **信息政策与惩罚政策开始在主指标上分开。** I − F 的真实改善差值从第一版的 −0.001 变为 +0.154 [−0.001, +0.309]（Holm p = 0.051），3 个种子分别为 +0.18、+0.08、+0.20。原因是饱和削弱了惩罚政策：F − B 从 +0.46 降到 +0.22，I − B 从 +0.46 降到 +0.37。开发规模只有 3 个种子，这只是需要用正式实验检验的假设。
4. **规模梯度更陡。** 大企业的漂绿决策占比从 82% 降到 73%，小企业从 35% 降到 15%。
5. **漂绿格局：评分贴近满分，真实水平远低于它。** 有虚报的企业日中，37% 的报告距满分不到 0.1 SD，这些企业的真实水平平均比满分低约 4.9 SD。成因是自然衰减持续为虚报腾出空间，而这一假设本身有疑问（见第 4 节）。

## 3. 三项诊断在第二版中的结果（[diagnosis.json](diagnosis.json)、[saturation.json](saturation.json)）

**漂绿确实发生。** 政策前 16% 的决策选择漂绿，政策窗口内为 33%。漂绿决策中 97% 是继续已有案件（第一版 96%）。没有未被发现虚报的企业每期只有 1.8% 开始漂绿（第一版 4.2%）。已有案件的企业继续漂绿的比例从 94% 降到 85%，因为报告贴近满分后已经没有可追加的空间。漂绿幅度平均 0.15 SD/期，顶到每期上限的比例从 66% 降到 33%。

**大企业更倾向于漂绿。** 罚款占市值比例的中位数仍是大企业 8.3×10⁻⁶、小企业 8.0×10⁻⁵。政策窗口的漂绿决策占比为大 73%、中 56%、小 15%；等成本对照为 69%、55%、18%。“开始漂绿”的比例随市值十分位从 0.3% 升到 3.5%。命题 1 的闭式阈值与实际选择的一致率为 99.9%，在产能约束不生效的决策中（占 97%）为 100%。

**透明度门槛：门槛以下逐步下降，门槛处的跳变仍在。**

| 透明度 τ | 0 | 0.1 | 0.3 | 0.5 | 0.55 | 0.575 | 0.6 |
|---|---:|---:|---:|---:|---:|---:|---:|
| 条件重算：全部决策 | 38.5% | 33.2% | 23.3% | 19.9% | 18.4% | 0 | 0 |
| 条件重算：开启新案件的决策 | 5.9% | 1.8% | 0.2% | 0 | 0 | 0 | 0 |
| 实际运行（第 1201 日起改变 τ） | — | 33.2% | 14.9% | 9.5% | — | — | 0 |

共同门槛仍是 τ* = 0.565。已有案件的企业没有边际罚款，在 τ* 处一起停止漂绿，所以跳变的成因与第一版相同，与饱和无关。

**边际威慑。** 罚款提到 4 倍后，“开始漂绿”从 1.8% 降到 0.3%，“继续漂绿”从 85% 降到 77%。漂绿减少主要是因为开启的案件变少。

## 4. 仍需研究决定的问题

第一版报告第 4 节的第 1 项（评分天花板）已由本版处理。其余三项仍未决定：

1. **罚款记账**（每次查处罚一笔，还是每份虚假报告各罚一笔）。它决定了边际威慑失效和门槛处的跳变。
2. **比例罚对照的量级。** 0.005/SD 在两版中都完全没有漂绿。
3. **自然衰减与成本随真实水平下降。** 第二版的典型漂绿企业，报告接近满分，真实水平比满分低约 4.9 SD。这一格局由两个假设共同造成：一是每年 0.2 SD 的统一自然衰减，它不断为虚报腾出空间；二是 `cost_level_elasticity` 让漂绿在真实水平低时更便宜。两者都未经验校准。上一次会话整理的[华证 2009–2022 面板](../huazheng_panel_dynamics_20261013/README.md)显示，评级呈现向中间水平回归，整体没有下降趋势；面板来源尚未核实，但它与“统一衰减”的假设不符。建议在阶段 F 之前决定衰减的形式。
