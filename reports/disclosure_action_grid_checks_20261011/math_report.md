# 固定多幅度网格的数学诊断

固定设计为rho=(.01,.02,.04,.08,.16,.32,.64,1)，不按诊断结果修改。cap=.25时，正幅度为(.0025,.005,.01,.02,.04,.08,.16,.25)初始SD；两种投资语义加维持共17个动作，经济语义仍为改善、虚报、维持3种。math_spec.json保存固定输入，math_checks.py只做代数与数组计算，没有导入市场模型、调用NPV最优生成候选或运行市场。math_checks.json记录实际结果、脚本及输入哈希。动态K的只读集成审查另见review.md，本数学诊断不代替市场验收。

## 投入额度与自然衰减

每60交易日一次决策、每年252交易日，旧单幅度的gross额度上界为.0025×252/60=.0105 SD/年，仅为自然衰减.2 SD/年的5.25%；远离下界截断时，净变化上界为−.1895 SD/年。新网格包含完整cap，gross额度上界为.25×252/60=1.05 SD/年，相应内部净变化的形式上界为+.85 SD/年。

这些只是按决策额度折算的上界。实施延迟、现有与在途存量、上下界、已知承诺可行性、成本、补贴和融资收益都会限制实际行动；接近上界时也不能无限维持最大投入。新网格使扭转内部衰减在额度上成为可能，不保证正NPV、QL会学会选择、实际净改善或政策有效。上面的净变化界还不适用于自然衰减已被下界截断的日期。

## 单一光滑二次目标的相对界

设某一种行动的快照目标为f(x)=a*x−c*x²，c>0，连续内部最优x*=a/(2c)>0。完成平方得：f(x*)−f(x)=c*(x−x*)²，且f(x*)=c*x*²。

若两个相邻**合法**网格点L≤x*≤U，r=U/L≤2，比较两端目标等价于选距离x*较近的一端。最坏位置是x*=(L+U)/2，因此：

`[f(x*)−max(f(L),f(U))]/f(x*) ≤ [(U−L)/(U+L)]² = [(r−1)/(r+1)]² ≤ 1/9`。

最坏损失为最优正效用的11.11%。前6个倍增区间的界均为1/9，最后.16至.25的比例为1.5625，界约4.82%。脚本逐区间检查2001个连续最优位置，并检查上述解析最坏点；数组检查只作复核，界限来自代数推导。

条件不能省略：同一光滑二次式、正最优效用、连续最优由两个合法点夹住。只有在这些条件满足时，才能把1/9用于该快照离散化误差；它不是学习误差、实际收益差或连续NPV整条路径的误差界。容量clip后若仍有满足上述比例的合法夹点，推导保持；可行性mask若删掉夹点，则不能继续套用原网格比。区间内相对界不依赖0是否合法，math_checks.json所列维持合法是检查样例采用的更强充分条件；维持合法是下段首格界所需条件。连续最优超过可实施上限时，含上限端点的约束问题另行处理，不能把无约束最优当作可实施参照。

## 首格以下只有绝对界

设最小正合法幅度为h，维持0合法，0≤x*≤h。比较0与h得：

`regret = c*min(x*²,(h−x*)²) ≤ c*h²/4`。

旧首格h=.0025、c=.05时，绝对效用误差上界为7.8125e−8（目标所用市值比例单位）。当0<x*≤h/2时可以选择维持而损失全部正效用，相对误差达到100%，所以不能声称首格以下也有1/9保证。若maintain非法或最小合法幅度改变，必须重新检查条件。NPV最低正效用阈值epsilon若额外令合法维持胜出，可在上述绝对遗憾界上再加epsilon；不能将其忽略。

## 报告容量拐点：明确反例

真实改善目标可为分段式：`f(x)=R*min(x,C)+R_displaced*max(x−C,0)+s*x−c*x²`。固定取报告剩余C=.03、R=.006、R_displaced=0、补贴s=0、c=.05。网格中相邻点为.02和.04，间距比仍为2。C处左导数+.003、右导数−.003，因此全域最优位于拐点.03。

连续最优效用为.000135；固定整张网格的最佳点.02和.04效用均为.000100。相对损失为(.000135−.000100)/.000135=7/27，约25.93%，明显超过1/9。更低点位于递增段、更高点位于递减段，其他固定候选不能消除此反例。全部固定候选的效用保存在math_checks.json；没有为接近最优而补入.03候选。

因此，多幅度网格改善了实质可行集与光滑区间的分辨率，但没有整个分段机制的统一11.11%误差保证。下一步只核验既定网格的容量去重、共同价值锚可行性、动态维度、探索概率、冻结元数据及语义指标；不据此变更网格、阈值或选有利结果。
