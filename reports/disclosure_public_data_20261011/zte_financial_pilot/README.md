[实际提取结果](matched_observations.json)通过发行人、股类、财务单位和加总关系核验；尚未构成同期联合校准样本，也没有运行或拟合市场。

[2023年报](https://static.cninfo.com.cn/finalpage/2024-03-09/1219266488.PDF)的PDF第10页明确中兴通讯股份有限公司、统一社会信用代码及A股000063/H股763。PDF第35页的总股数4,783,251,552等于A股4,027,749,018加H股755,502,534。WBA的ISIN `CNE1000004Y2`在已取得的港交所证券表中对应港元H股00763，不能直接当作A股证券标识；同一法律发行人的对应另由年报确认。

年报PDF第107—109页的合并报表以人民币千元计。2023年末资产200,958,318千元，负债132,626,873千元，总权益68,331,445千元；总权益又等于归母普通股权益68,008,307千元与少数股东权益323,138千元之和。提取结果乘1000转为人民币元，保留原报告精度、页码和标签。账面权益不等于市值或模型潜在价值，市场价格、市值及账面市值比仍为空。

三个日期口径分开保存：WBA的2023评估为6/20的社会维度代理，其46条指标证据引用2020年政策及2021年报告；上述财务截至2023-12-31；[华证官网](https://www.chindices.com/esg-data.html)实际响应的综合分92.9、AA，日期为2026-09-24。它们不能拼接成2023年综合ESG与财务同日样本，也不能由评分分解出真实能力及漂绿。

港交所下载件标注“Updated as at 12/10/2026”，晚于本次11日取得时间；原标签已保留，只作为本次证券标识参考，不推断2023年名单。WBA旧网页和2021年报的一次下载未成功，失败记录保留，没有改用2023年报冒充2021年资料。
