## 已核实的官方接口事实

[SEC API 文档](https://www.sec.gov/search-filings/edgar-application-programming-interfaces) 说明公开查询无需 API key；submissions 使用十位 CIK，companyfacts 汇总公司 XBRL，区分计量单位，并覆盖标准 US-GAAP/IFRS taxonomy。实时接口会更新，下载时必须留版本。当前财务事实端点：`https://data.sec.gov/api/xbrl/companyfacts/CIK##########.json`；公司元数据端点：`https://data.sec.gov/submissions/CIK##########.json`。

[SEC Developer FAQ](https://www.sec.gov/about/webmaster-frequently-asked-questions) 要求声明请求者 User-Agent，当前最高速率为每秒 10 次；提供的 company_tickers.json 关联公司名、股票代码和 CIK，但不保证准确性及覆盖。官方名称映射入口：`https://www.sec.gov/files/company_tickers.json`。

## WBA 到 CIK 的匹配设计

WBA ID 是本地来源键；CIK 是 SEC 法律申报实体键，不能从 ISIN 字符串直接换算。原始公司名、国家、年份和 ISIN 原值不改。保留候选与确认两个层级。

- 名称规范化、当前 ticker 对照只能提出候选，不能独立确认。同名、简称或同一集团不足以通过。
- 确认使用 SEC submissions 的现名、曾用名与注册信息，并结合公司官方披露的集团/上市/子公司关系。实体与 WBA 评分范围不同的情况保留 ambiguous，不能把集团评分随意赋给子公司申报。
- 当前来源中的重复、缺失、占位或带内部空格 ISIN 均进入待审；即便格式与校验通过，也需核实所有权和生效日期。未经证据确认不纠错或去重。
- 每条记录至少保存 wba_id、原始评估年份、候选 cik、确认 cik（十位字符串）、match_status、匹配规则、来源链接、核实 UTC、实体关系及判断备注。未确认值保持空白；一对多、多对一需显式理由。
- 对被排除、无 SEC 申报、财务缺失和非上市机构逐项报告覆盖，并比较入选/未入选的年份、国家、行业与 CSI 分布。SEC 子样本不能直接代表全球 WBA 样本。

## 财务字段与时间设计

以下是待实施的抽取规范，不是已经取得的字段或经验估计。

每条事实保留 taxonomy、tag、unit、start/end、form、filed、accn、fy/fp、frame 和原始 value。优先年度申报 10-K、20-F、40-F；期间长度和财年需另核对，不按行号或 JSON 最后一条选值。区分 instant 与 duration；不混合 USD 与其他货币、不重复计入修订申报或相同事实。

财务期与评分年匹配并不保证可同时观测。若研究信息集定义在 2024-04-17 数据页发布时，只使用 filed 不晚于该截点的事实，并记录选择规则；当前下载的 companyfacts 可能含后来重述，不能将其作为当时已知值。若无法确认历史评分可用时点，校准只称发布后截面描述，不称历史预测或因果识别。

可优先审查总资产与经营现金流作为规模、支付能力候选；必须保存具体标签与口径差异。总资产不等于市值，不能静默替代当前模型按市值划分的企业规模。长期/短期债务及利息费用需要核对租赁、资本化利息、债务边界及平均余额；简单费用/期末余额不等于前瞻融资利率。dividend yield 也不等于债务资金成本。

最低技术验收：来源和输出哈希、身份映射证据、单位/期间检查、重复与修订处理、小批原申报手工对照、缺失与失败覆盖、固定截点可复现。最低研究验收：确认实体可比性和选择偏差，另行冻结真实融资定价与现金流假设；财务接入不会自动识别偏好、成本或政策因果作用。
