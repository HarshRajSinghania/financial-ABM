# Wind 数据需求清单（2026-10-13）

目的：用真实数据替换模型中目前只是假设的参数。每一项都写明用途，如果某项导出困难，可以先跳过，按优先级来。

**存放位置**：`data/raw/wind_YYYYMMDD/`（例如 `data/raw/wind_20261013/`）。这个目录已加入 `.gitignore`，**不会被提交或推送到 GitHub**；Wind 数据只用于本地研究，仓库里只保留处理脚本和汇总结果。

**通用格式要求**
- CSV（UTF-8）或 xlsx 都可以；一个数据集一个文件。
- 长表格式：每行一个“证券 × 日期”（或一笔事件），包含 Wind 代码（如 `600887.SH`）和证券简称。
- 保持原样导出，不要手工删改或排序。缺失值留空即可。
- 每个文件附一行说明（或另附 `说明.txt`）：导出日期、Wind 字段名、单位（元 / 万元 / %）、报告期口径、复权方式。字段名以终端显示为准，我会据此对应。

**样本范围**：优先**全部 A 股**，这样可以避免只用沪深 300 带来的选择偏差。如果导出量受限，最低要求是**中证 800（沪深 300 + 中证 500）**，并注明是按哪一天的成分。

## P0：必需（直接决定下一步能否校准）

### 1. 华证 ESG 评级历史面板（最重要）

| 字段 | 说明 |
|---|---|
| 华证 ESG 综合评级 | AAA–C 九档 |
| 华证 ESG 综合得分 | 如果有 |
| E、S、G 分项评级与得分 | 如果有 |
| 评级日期 | 每条评级的生效日期 |

- **时间**：2009 年至今，**季度**（华证按季度更新；如果能取到更细的频率，就按实际频率）。
- **用途**：评级的持续性和升降级概率，用来校准“自然衰减”和“每期最大改善幅度”，这两项现在完全是假设；同时检验评级是否会突然跳升，这是漂绿的一个可能信号。

### 2. 融资成本（二选一即可，都有更好）

**2a. 企业层面的债务成本**（年度或半年度，2009 年至今）

| 字段 | 说明 |
|---|---|
| 利息支出（或财务费用中的利息费用） | 利润表 / 附注 |
| 短期借款、长期借款、应付债券、一年内到期的非流动负债 | 用来计算有息负债 |
| 报告期、公告日期 | 用来判断数据何时可知 |

**2b. 债券层面的信用利差**（发债公司，2015 年至今）

| 字段 | 说明 |
|---|---|
| 债券代码、发行人 Wind 代码 | 对应到公司 |
| 发行日、到期日、期限、票面利率 | 发行信息 |
| 主体评级、债项评级 | 用作控制变量 |
| 中债估值收益率（月末）或发行利率 | 如果有 |
| 债券类型 | 企业债 / 公司债 / 中票等 |

- **用途**：在我们自己的样本里估计“ESG 每提高 1 个标准差，融资成本下降多少基点”，替换目前借用文献的 28 个基点。这是决定企业会不会漂绿的关键参数。

### 3. 公司特征面板（年度末或季度末，2009 年至今）

| 字段 | 说明 |
|---|---|
| 总市值、流通市值、总股本、收盘价 | 规模 |
| 归属母公司股东权益、总资产、资产负债率 | 资本结构 |
| ROA 或净利润 | 盈利 |
| 申万一级行业 | 行业 |
| 企业性质（国企 / 民企等） | 产权 |
| 上市日期 | 样本筛选 |

- **用途**：融资成本回归的控制变量；规模分档；评分与规模相关性随时间的变化。

## P1：重要（支撑新智能体和关键预测）

### 4. 其他机构的 ESG 评级（同一样本、同一时间范围）

Wind 自有 ESG 评级、商道融绿、MSCI、彭博 ESG 披露得分、富时罗素等，有哪家就导出哪家（评级或得分、日期）。

- **用途**：评级分歧是文献中常用的“漂绿或测量噪声”代理变量，可以用来校准披露噪声，并检验模型的预测：在定额罚款下，大公司更倾向于漂绿。

### 5. 违规处罚记录（事件表，2009 年至今）

| 字段 | 说明 |
|---|---|
| 公司 Wind 代码、处罚日期、公告日期 | |
| 处罚机构 | 证监会 / 派出机构 / 交易所 / 生态环境部门等 |
| 处罚类型 | 罚款、警告、通报批评、监管函等 |
| 违规类型 | 尤其是虚假陈述、信息披露违规、环境违规 |
| 罚款金额 | 元 |

- **用途**：估计检出概率和罚款金额的分布，替换目前按法条上限的设定；并区分“交易所纪律处分”和“行政罚款”。

## P2：有更好（扩展用）

- **社会责任 / ESG / 可持续发展报告的披露情况**：是否发布、发布日期、是否有第三方鉴证。用于“鉴证方”智能体和披露时点。
- **沪深 300 历史成分**：若干历史时点（例如每年 6 月和 12 月）的成分名单，用于处理幸存者偏差。
- **分析师一致预期**：EPS（FY1、FY2）、每股股利、每股净资产，用于计算隐含权益资本成本。
