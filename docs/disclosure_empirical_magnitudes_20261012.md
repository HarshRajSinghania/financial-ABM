# 漂绿罚则与 ESG 融资收益：经验量级检索（2026-10-12）

目的：为[漂绿条件诊断](../reports/disclosure_wash_diagnosis_20261012/README.md)中的关键比值——预期罚金 / 融资收益——寻找有出处的量级。本文只整理证据并换算到模型单位，**没有修改任何参数**。

## 5. 换算到模型单位（沪深 300 联合样本）

- 评分 1 SD = 7.24 分 ≈ **1.45 个华证评级档**（约 4.9 分一档；样本评级档均值 7.0，标准差 1.45）。
- 市值中位数 1.0×10¹¹ 元（5%–95% 分位：3.9×10¹⁰ 到 8.7×10¹¹）。

| 量 | 模型当前值 | 经验锚点（换算后） | 比较 |
|---|---|---|---|
| 罚金 p（每 SD，占市值比例） | 0.005 | 法定上限 1000 万元 / 中位市值 = **1.0×10⁻⁴**（按市值分位为 3.5×10⁻⁴ 到 3.4×10⁻⁶）；2025 年平均罚款 1,793 万元 → 1.8×10⁻⁴；可持续发展报告本身：没有罚款 | 模型罚金约为法定上限的 **50 倍** |
| 检出（折现后的最终检出概率） | D = 0.455 | 约 1/3 的欺诈会被发现（美国财务欺诈，未折现） | 数量级一致 |
| 融资收益（1 SD 报告改善对应的利率下降） | B / 敞口比例 ≈ **0.9 个基点** | 0.19 个百分点 × 1.45 ≈ **28 个基点**（权益成本，横截面相关）；贷款 7–18 个基点（美国，问题企业与非问题企业之差） | 模型偏小 **10–30 倍** |
| 揭露后的全部损失 | pD ≈ 2.3×10⁻³（每 SD） | 单次事件 −0.2% 到 −0.4% 市值（均值常不显著，且含溢价损失） | 如果把模型罚金理解为“全部损失”而不是“监管罚款”，量级大致相当 |

## 6. 对模型的含义（需要研究决定）

1. **罚金的含义要先定下来。** 如果 `penalty` 代表监管罚款，经验锚点约为 10⁻⁴，模型高估约 50 倍；如果代表揭露后的全部损失，当前量级大致可以接受，但其中失去溢价的部分会与信号消失重复计算。两种解释不能混用。
2. **罚款形式与模型结构不匹配。** 法定罚款是有上限的定额（元），模型罚金却按“市值 × 虚报 SD”成比例计算。这意味着模型让大企业承担了巨额的绝对罚款，而现实中罚款占大企业市值的比例极小（中位市值公司 1×10⁻⁴，最大的公司 3×10⁻⁶）。由于规模异质性是核心研究问题，这个结构差异会直接影响“规模—政策”结论。
3. **融资收益很可能低估了 10–30 倍。** 融资收益在模型中由投资者偏好、价格冲击和融资合同共同内生决定。比较正当的做法是把“每 SD 对应的融资成本斜率”作为经验校准目标（例如约 28 个基点，要说明这是权益成本的横截面相关、不是因果效应），而不是直接改利差参数。
4. **按经验量级，模型会进入“罚款不起作用、透明度决定一切”的区域。** 粗略换算：融资收益放大约 30 倍、罚款按法定上限计算时，预期罚款远小于漂绿收益，企业是否漂绿几乎完全取决于透明度是否低于 τ* = 1 − √w·A_r/A_w ≈ 0.565。这又会遇到诊断报告中指出的“全有或全无”问题。漂绿成本比例 w = 0.2 本身也没有经验依据，而它直接决定 τ*。
5. 在做出 1–3 的决定并写入研究契约之前，不应据此调参后重跑政策实验。
