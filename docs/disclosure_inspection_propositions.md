# 检查博弈中企业一方的两个命题（2026-10-13）

> **状态：参考。** 这是[现行计划](plan_20261013.md)阶段 B 要求写出的解析基准。命题描述的是模型中 NPV 企业的决策规则 `npv_choices`，数值核对见 [`tests/test_disclosure_fixed_fine.py`](../tests/test_disclosure_fixed_fine.py)。监管者在这里不是策略性参与者：核查概率、罚款和透明度都是给定的，所以下面是企业对给定检查政策的最优反应条件。策略性监管者属于阶段 E。

## 1. 设定

对一家企业的一次决策（下标 i 在不引起歧义时省略）：

| 符号 | 含义 | 代码 |
|---|---|---|
| B | 每 SD 信号带来的年化融资节约，占当前市值的比例 | `marginal_financing_saving()` |
| A_r、A_w | 真实改善与虚报的信号年金（年），由实施或披露延迟、重定价日历、核查存续和贴现决定 | `financing_signal_factors` |
| D | 检出折现因子：在新虚报被查获时支付 1 单位的期望现值 | 同上，第四个返回值 |
| c、w | 真实改善的边际成本系数；虚报成本相对真实改善的比例 | `marginal_cost`、`wash_cost_ratio` |
| τ、p、s | 透明度；比例罚（每 SD 虚报，占市值）；补贴 | `PolicyRegime` |
| F、P、f | 定额罚款（模型货币单位，每查处一次罚一笔）；当前市值；f = F/P | `fixed_fine` |
| π | 新虚报开启一个新案件的概率 | `new_case_probability` |

一次核查发现虚报即为一个案件：比例罚按当时的虚报总量计算，另加一笔定额罚款，虚报清零。新虚报在披露日（决策日 + 披露延迟）并入报告。如果此时报告中还有未被发现的虚报，它就并入同一个案件，不再多罚一笔定额罚款；只有披露日之前的核查才可能先把旧案件查结。在默认时序下（披露延迟 20 日，核查间隔 60 日），有未被发现虚报的企业 π = 0，其余企业 π = 1。

不触及产能上限（每期最大变动、报告剩余空间）时，三种行动的价值为：

- 真实改善：V_I = (B·A_r + s)² / 4c，幅度 (B·A_r + s) / 2c；
- 虚报：V_W = max(B(1−τ)A_w − pD, 0)² / 4wc − π·f·D，幅度 (B(1−τ)A_w − pD) / 2wc；
- 维持：0。

企业选价值最大的行动，平局时维持。

## 2. 命题 1：定额罚款下的漂绿条件和规模阈值

**命题 1.** 设 s = 0、p = 0、π = 1，且 τ < τ*（见命题 2）。企业选择虚报，当且仅当

  B²·[(1−τ)²A_w²/w − A_r²] > 4·c·f·D，

等价地，当且仅当它的市值超过

  P* = 4·c·F·D / (B²·[(1−τ)²A_w²/w − A_r²])。

*证明.* B > 0 时 V_I > 0，所以虚报必须胜过真实改善：B²(1−τ)²A_w²/4wc − fD > B²A_r²/4c，两边乘以 4c 即得。把 f = F/P 代入解出 P。∎

推论：

1. **做或不做。** 定额罚款不改变虚报的幅度，只决定虚报与否。这是它和比例罚的根本区别：比例罚以 pD 压低每 SD 的净收益，从而同时改变幅度。
2. **规模方向反转。** f = F/P 随市值下降。B 是融资节约占市值的比例，与规模大致无关；默认的规模成本乘子 [0.6, 1, 1.6] 又让大企业的 c 更低。两者都使大企业先越过 P*。比例罚下的条件是 B[(1−τ)A_w − √w·A_r] > pD，规模只通过 B 进入。
3. **边际威慑失效。** 对 π = 0 的企业（新虚报会并入未被发现的旧案件），条件退化为 τ < τ*，与 F 无关。提高 F 只能阻止企业开始虚报，不能阻止已经在虚报的企业继续。基准核查概率为每 60 日 1%，一个未被发现的案件平均要存续约 100 个决策期。

## 3. 命题 2：透明度门槛

**命题 2.** 设 s = 0、p = 0。企业 i 选择虚报，当且仅当 τ < τ_i*，其中

  τ_i* = 1 − √w · √(A_r² + 4·c_i·π_i·f_i·D / B_i²) / A_w，

并且 τ_i* ≤ τ* ≡ 1 − √w·A_r/A_w，当且仅当 π_i·f_i = 0 时取等号。比例罚下对应的门槛是 τ_i* = 1 − (√w·A_r + pD/B_i)/A_w。

*证明.* 由命题 1 的不等式对 (1−τ) 求解；比例罚的情形由 B(1−τ)A_w − pD > √w·B·A_r 求解。∎

推论：

1. **没有罚款时门槛是共同的。** π_i·f_i = 0 时，所有企业的门槛都是 τ*，与成本、规模、融资收益无关，总体反应是“全有或全无”。[2026-10-12 的诊断](../reports/disclosure_wash_diagnosis_20261012/README.md)发现的正是这种情况：默认时序下 A_w/A_r ≈ 1.03，w = 0.2，τ* ≈ 0.565。
2. **定额罚款把门槛分散开。** 门槛按 c_i·f_i/B_i² 在企业之间分布，于是选择虚报的企业比例随 τ 在 τ* 以下的一个区间内逐步下降，而不是在 τ* 处跳变。大企业的门槛更接近 τ*。这个过渡来自规模和成本的异质性，这两者都有经验或假设依据，不需要另外引入贴现率或时间结构的异质性。
3. **已在虚报的企业门槛仍是 τ*。** 它们的 π = 0，信息政策要把 τ 提到 τ* 以上才能让它们停止虚报。

## 4. 适用范围

- 只覆盖内点解。产能上限生效时，价值按截断后的幅度计算，结论需要用截断值重新比较；`npv_choices` 和测试中的暴力枚举都包含这种情形。真实改善超出报告剩余空间时的“替代虚报”分支，以及补贴，都没有写进闭式。
- NPV 是逐期决策，不预见自己未来的选择。例如第一次虚报不会计入“以后再虚报不用另交定额罚款”的选择价值。命题描述的是模型的决策规则，不是动态最优解。
- B 是局部报价反应，在整个预测期内保持不变；其他企业的行动和价格动态造成的反馈不在其中。A_w 和 D 假设当前政策一直延续。
- 开启评分饱和（契约第 17 节）后，报告的上界是可观测满分 C，而不是潜变量的数值边界。这只改变产能：漂绿和真实改善的剩余空间以 C 为界，命题在 C 以下的内点情形不变。
- 报告上界（线性映射下是刻度端点，开启饱和时是 C）会在真实改善把报告顶到上界时清掉虚报，案件因此不经查处就结束。`new_case_probability` 忽略这一点。

## 5. 三个可选设定下的命题（契约第 20.21 条，2026-10-18）

三个设定默认都关闭，关闭时上面的命题和代码逐位不变。

**按报告计罚（`fixed_fine_basis = "report"`）。** 核查发现虚报时，按未被查出的虚假报告份数各罚一笔 F（每次漂绿决策在披露日形成一份）。一份新报告无论是否并入未查出的旧虚报，都会在它所在的存量被查出时多罚一笔；旧报告的罚款与新决策无关，是沉没的。所以新虚报的预期定额罚款恒为 f·D，即命题中的 π_i ≡ 1：

- 命题 1 对所有决策成立，包括已有案件的企业：企业 i 虚报当且仅当 P_i > P*。
- 推论 1.3（边际威慑失效）不再成立：提高 F 同样能让已在虚报的企业停止追加虚报。
- 命题 2 的 τ_i* 对所有企业都按 π_i = 1 计算；推论 2.3 不再成立，τ* 仍是上界，只在 f = 0 时取到。
- 与第 4 节一样，忽略报告上界清掉虚报（份数随之清零）的情形。

**异质漂绿成本（`wash_cost_log_sd` > 0）。** 每家企业有自己的 w_i，命题照常成立，只是把 w 换成 w_i。推论 2.1 改为：没有罚款或已有案件时，企业 i 的门槛是 τ*(w_i) = 1 − √w_i·A_r/A_w，不再是共同的；选择虚报的企业比例随 τ 按 w_i 的分布逐步下降，τ 越高，能虚报的只剩 w_i 越低的企业。命题 2 给出必要条件：τ*(w_i) ≤ τ 的企业不会虚报（内点情形）。

**向截面均值回归（`natural_reversion` = κ > 0）。** 真实水平围绕当日截面均值做均值回归，并有使截面方差平稳的个体冲击。冲击与行动无关，不进入边际价值；真实改善 Δ 在实施 d 日后只剩 Δ·[1/N + (1 − 1/N)·e^(−κd/252)]。因此 A_r 按这一衰减计算，记为 A_r(κ) < A_r；虚报的存续只取决于核查，A_w 和 D 不变。命题 1、2 把 A_r 换成 A_r(κ) 后照常成立，于是门槛 τ* = 1 − √w·A_r(κ)/A_w 上升。在默认时序和主设定的贴现下，w = 0.2 时 τ* 由 0.565 升到 0.766（κ = 0.32/年）与 0.824（κ = 0.50/年）。被真实改善替代的虚报不会恢复，所以替代分支的损失项不变。只实现了连续报告、核查结果不公布的时序。
