## 1. 比较对象与共同约束

保留现有 continuous `npv` 默认及其数值行为。算法对照必须是共同离散候选的 `npv_discrete` 与 QL；连续 NPV 单列额外参考，不把不同可行集的差异解释为学习算法效果。

配置 `firm_action_fractions` 为固定递增幅度列表，基本幅度为 `rho*domain.max_change_per_period`。旧默认 `(.01,)` 保持3个选项；新开发规格固定 `(.01,.02,.04,.08,.16,.32,.64,1)`，真实/虚报各8档及维持，共17个内部选项。这是分辨率和可行集假设，不是经验投资规模估计。索引0/1是最低档真实/虚报，2为维持，后续依次为更高档真实/虚报；经济动作输出仍为0/1/2，独立 `learning_choices` 保存多档内部编号。容量沿用真实存量、虚报存量及在途预留，不读取 NPV 最优幅度。截断后同类型金额完全相同的候选仅保留最低编号；不逐公司压缩或重新编号。负 NPV 不使动作非法。

旧单档每60日最多改善 .0025 SD，投入上限 .0105 SD/年低于假定自然衰减 .2 SD/年，旧冒烟结果保留作集成证据。新网格包含完整 cap=.25，形式投入上限为1.05 SD/年；这只解除额度上的限制，不保证有利可图或净改善。自然衰减不改，网格不按结论方向选择。光滑单二次目标、两个合法正幅度夹住内点最优且相邻比≤2时，快照相对损失界为1/9；首格以下只有绝对界。真实报告容量拐点、可行性掩码删掉夹点时没有此统一相对保证，见[数学诊断及反例](../reports/disclosure_action_grid_checks_20261011/math_report.md)。不同可行集与连续 NPV 的差异不能归为学习算法效应。

两种离散规则共同排除已知承诺应用后价值锚非正或非有限的选项：`V + pending_value_change + (subsidy_fraction-cost_fraction-audit_penalty_fraction)*P > 0`。这对应既有价值记账条件，不代表企业现金预算或现实偿付能力。维持也可能非法，而补贴使真实改善合法；仅全部选项非法时报错。下一日基本面冲击仍可能导致市场失败，须保留失败记录。

两种离散模式共用候选金额、c*delta²/omega*c*delta² 资源成本、补贴、实施/披露延迟、核查与融资机制。成本 c 的单位为市值比例/SD²，罚金/补贴为市值比例/SD；承诺金额乘决策日市值，下一日按原绝对金额进入价值锚。候选的实际生效均走同一市场调度，不复制 QL 状态演化。

离散 NPV 采用当前融资预测器提供的每SD现值系数：完整真实信号 R、挤出虚报后的真实信号 R_displaced、虚报融资收益 W、预期罚金 K。设 report_capacity 为剩余报告容量：

`V_real = R*min(delta_real,report_capacity) + R_displaced*max(delta_real-report_capacity,0) + subsidy*delta_real - c*delta_real²`；

`V_wash = (W-K)*delta_wash - omega*c*delta_wash²`；`V_maintain=0`。

固定/时变政策的系数由同一个融资预测器计算，学习组件不另写未来政策或审计公式。离散 NPV 按合法候选最大值选择；最优值不超过现有 MINIMUM_NPV 且维持合法时维持。并列优先合法维持、真实改善由低至高档、虚报由低至高档。QL 不使用这组效用或排序作奖励、标签或状态。

## 2. 实际奖励、时钟与截断

固定公司初始市值 P_i,0 为归一化基准。决策时点 t 到下一决策 t' 的奖励：

`r_i,t = sum_{d=t+1..t'} exp[-firm_discount_rate*(d-t)/252] * [financing_value_adjustment_i,d - applied_resource_cost_i,d - applied_fine_i,d + applied_subsidy_i,d] / P_i,0`。

financing_value_adjustment 是实际计提的 `F*(r_initial-r_contract)/252`，也等于初始合同基准费用减实际合同费用。它是私人成本基准差额，不是已识别的政策因果节约。另三项取实际应用日的原币金额，不能使用当前市值再次缩放。不能再加入股价、股息收益率、内在价值变化、NPV、预期罚金或估值涨幅奖励；同一融资差额不能从价值变化再记一次。融资费用是私人成本/对手方收入，资源成本与财政转移须分项保存，奖励不是社会福利或实际现金利润。

决策日顺序保持交易→核查→决策。日 t 的核查罚金在 t+1 实际应用，归新区间(t,t']，不属于已经关闭的前一区间；它与当前新动作无直接因果对应。状态在核查后、新动作前拍摄，并包括这个已知未应用的现金承诺；使用各项承诺总额，不因成本与补贴相抵而误判为无承诺。前一区间 TD 目标通过下一状态传播责任，不能清掉罚金或把全部窗口收益归给最近动作。事件可由(决策/核查周期,公司,成本/罚金/补贴)唯一索引，应用日为次日；成本和补贴归该决策，罚金归该次核查的聚合虚报存量，不伪造单个来源动作。每日台账按应用日求和，相邻开闭区间覆盖一次。公司在 t' 新承诺的项目成本于 t'+1 应用，进入下一窗口。

周期折扣 `gamma(t,t')=exp[-firm_discount_rate*(t'-t)/252]`；D=60、年率=.05 时约 .988165，不沿用无年度解释的 .9。窗口内折现乘周期 gamma 必须等于从最初决策逐日折现。

真实改善延迟可跨2或3个周期，多项行动重叠；即时成本、缓慢融资收益和罕见核查会使短样本 QL 偏向维持或低估责任。完整队列和责任台账保留，压缩状态不消除这种偏差。

时间上限是截断，不是吸收终止。训练最后一条已结算转移仍用停止前市场的下一状态/合法掩码 bootstrap；不得从重新初始化的世界取状态，不得清空在途后令 target=reward。最后一次尚无完整下一窗口的动作不伪造转移，列出未结算决定、已承诺支出、待生效项目和未查获虚报。初始决策前无前驱动作，已有费用只进基准台账。只有全部未来奖励/责任均为零的真实吸收小环境才设置 terminated=True，禁止 bootstrap。评估不更新；有限窗口奖励与未完成责任分别报告，不能称为完整终生利润。若要比较完整项目利润，须另立共同尾部结算契约，不能默认剩余责任消失。

## 3. 状态、共享表与接口

复用 `CompanyQLearner` 的81状态表，动作维度按网格为 `2*len(firm_action_fractions)+1`，旧默认仍为3。四个三档特征固定如下；评估前冻结阈值，不用每日重新标准化：

| 特征 | 定义 | 三档边界 |
| --- | --- | --- |
| 融资暴露比 | F/(F+P)，零F为0 | .25、.50 |
| 虚报存量 | 未乘透明度的 inflation，固定初始SD | 1e-12、domain.max_change_per_period |
| 相对边际成本 | log(c/domain.real_cost_scale) | −.5、.5 |
| 在途阶段 | 0无项目/现金承诺；1有下周期到期项目或次日现金承诺；2仅有更晚项目 | .5、1.5 |

多个项目并存时阶段1优先；完整数量、到期日、待应用罚金等仍保留原始诊断。分组为原规模组0..2加3*policy_epoch，epoch表示已进入实际干预制度，组数最多6；下一状态可进入新组。每个市场/政策场景分别训练表，制度标识不能在训练中不可见、评估时再强求无条件适应。

状态没有完整队列、现金承诺金额、对手持仓、需求斜率、全部价格/协方差、未来制度切换时间；一般时钟下也未表达重定价相位。因此是部分观测的表格近似，多家公司共同学习还使环境非平稳，不能承诺 Markov 性或全局最优收敛。最小比较先限定决策与重定价均60日；其他时钟须重新验收覆盖。

默认的各场景独立训练中，未来制度收益会通过 TD 更新进入干预前的 Q 表。仅在实际干预后改变 epoch 不保证各场景干预前行为相同，不能直接将各政策表的后期差异解释为第601日突然干预的纯因果效果。第6节的可选共同前表协议用于固定干预前行为；旧结果继续按原协议解释。

旧 `CompanyQLearner.update` 按ID逐个更新、总是 bootstrap，不能处理下一组和合法掩码，不能直接用作本比较。独立 `disclosure/learning.py` 提供兼容入口，保留原类、旧方法及其他ABM行为：

- `discrete_candidates(...) -> CandidateSet`：amounts、cost_fraction、subsidy_fraction、values、valid_actions 均为 N×K，kinds 保存每列经济动作；效用系数由市场传入。
- `context_states(...) -> states`：固定上述特征；输入融资暴露、价格、虚报、边际成本、最早项目到期差和待应用现金金额。
- `choose_actions(learner,groups,states,valid_actions,rng,training=...)`：探索先均匀选合法经济动作类型，再均匀选该类型合法幅度；最大Q并列的训练选择也按此分层，避免幅度数量自动挤压维持概率。训练使用独立RNG；评估epsilon=0，按固定优先序取最大Q；未访问状态取合法维持，否则取优先序中首个合法选项。旧3选项采样表达式保留。
- `realized_rewards(financing_savings,resource_cost,fines,subsidies,initial_cap,start_day,end_day,annual_discount_rate)`：每日原币数组，切片(start,end]，返回每公司窗口奖励。
- `batch_update(... next_groups,next_states,next_valid_actions,elapsed_days,annual_discount_rate,terminated)`：拍摄整个旧Q表，以合法下一动作最大值生成目标；同(group,state,action)汇总均值，只更新一次。alpha=.1表示每批键更新率，计数增加真实样本数；满足行排列及公司重编号不变性。
- `save_frozen` / `load_frozen`：表、访问计数、超参数及冻结元数据存档；保存返回SHA256，读取可校验预期哈希/元数据，Q/计数只读、epsilon=0，更新冻结表报错。

## 5. 最小代码触点与验收顺序

已实现 `disclosure/learning.py` 与市场/配置/单次归档集成。`firm_policy` 区分 npv、npv_discrete、q_learning；QL 必须显式提供学习表和训练/评估模式。runner 将完整环境（除随机种子和比较规则）、领域、政策、候选合同及源码哈希与表绑定，归档初末 Q 和访问计数；评估要求只读表及零探索，并核对前后不变。失败保留状态和可保存的部分表，不自动重置续接。旧 tabular update 不改。

必须通过以下验收才能进入预算训练：

- 共同候选按相同容量截断，负NPV虚报仍可被训练探索；实际应用金额、延迟、成本、补贴一致。continuous NPV回归保持原行为。
- 固定实际轨迹时改变NPV效用不改变QL奖励；核查日罚金在次日进入正确窗口，成本/补贴各计一次，相邻窗口贴现奖励与整段计算一致。
- 至少2/3周期真实延迟、重叠项目和次日罚金责任的确定性小环境：能学会“短期亏损、长期净收益为正”的行动，排除已知负收益行动。先固定玩具参数/预算，不能只验证公式相等。
- 非法动作从不选，训练可探索正容量负NPV动作；时间截断保留合法bootstrap，真吸收终止去掉bootstrap；不构造未结尾部样本。
- 批更新行排列与重编号不变；冻结读写哈希可核对，评估不更新Q/计数，禁止更新只读表。
- 未访问状态、并列、制度切换、零容量、市场失败有明确诊断。失败种子保留，不伪造惩罚奖励或重置后续样本使其通过。

这些门槛证明组件与比较契约成立，不证明实际市场训练充分或政策排序已支持。M4完成还需要端到端训练、冻结配对评估和覆盖验收。

## 6. 可选覆盖探索与共同干预前表

`coverage_target` 默认0，保留原采样。正值时，在合法选项中优先选择“已完成TD样本数＋本批预留数”最低且未达目标的选项；并列仍按类型、幅度分层抽样，沿用原有随机数。预留按输入公司顺序分配，只有真实闭合转移才增加训练计数。动态合法掩码使这种分配依赖顺序，不保证每个选项最终达到目标；最后一个没有完整后续窗口的决策不启动配额分支。`coverage_forced` 记录配额分支是否执行，不声称选择必然不同。报告区分强制决定、后续实际用于学习的样本和未结算决定；20条样本不等于20次独立批更新。覆盖验收仍使用原门槛。

`common_prepolicy_model` 与其 SHA256 必须同时提供。来源须是相同环境、领域、网格、基线、探索协议及源码下独立从零训练、预算完整完成的冻结基线表。只复制规模组0..2的Q值和真实计数；组3..5从零开始。来源训练和声明验证种子不得用于后续训练或验证，保留种子也不得交叉使用。来源文件按已归档路径保留，每次运行重新核对；单独提供任意哈希或自称共同来源的元数据不能通过归档入口。

政策前只按共同表贪心决策，不探索、不更新。跨越切换点的旧动作仍完整记录实际奖励及在途责任，但不回写政策前表；只有源动作属于政策后组的完整窗口才更新。基线对照也须显式切换到相同政策，以保持相同分组和时钟。`learning_transition` 表示窗口已结算，`learning_update` 单列实际参加学习的样本。1000/200、3500日、D=60、第1201日切换时，每个世界共11400条完整公司转移，其中7400条用于政策后学习；末次3480日动作的20日尾部不伪造完整转移。

这种协议比较“共同基线之后部署分别训练的条件策略”，不代表企业在政策出台后从零在线学习。来源完整性检查也不等于来源覆盖合格：冻结文件在验证前保存，正式部署仍须核验来源的真实验证报告，且后续场景各自通过覆盖和市场门槛。工程冒烟允许保留不充分表以检查数据流，其结果不能用于政策结论。
